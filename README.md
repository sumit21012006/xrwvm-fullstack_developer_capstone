# Dealerships - Full Stack Cloud Developer Capstone Project

A comprehensive, full-stack responsive web application for a national car retailer dealership network in the United States.

## Project Overview
This application enables customers to browse dealership branches across all U.S. states, view customer reviews with automated sentiment analysis, and post their own dealership reviews.

## Architecture & Technology Stack
- **Frontend:** React.js, HTML5, CSS3, Bootstrap 5
- **Backend Application:** Python Django, SQLite
- **Database & Microservices:** Node.js, Express.js, MongoDB (Dealerships and Reviews data)
- **Sentiment Analysis Microservice:** Python Flask, NLTK (SentimentIntensityAnalyzer)
- **DevOps & Deployment:** Docker, GitHub Actions (CI/CD), IBM Cloud Code Engine
